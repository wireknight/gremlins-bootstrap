## Summary
- What is wanted: the model-free proven-build contract (`build-step.py`,
  `gh-build.py`) and the single GitHub CLI door (`gh-safe.py`, `_gh_safe.py`).
  LOCAL mode may dispatch builds and long test lanes to GitHub Actions; no
  member may start a cloud AI task. A build checks out exact requested bytes
  (a commit, or commit plus proven patch), builds without cache, writes
  provenance, concludes BEFORE upload, and classifies every run on the
  record. The artifact, not the job's conclusion or an agent's report, is
  the evidence.
- Why it matters: moving AI off GitHub must not throw away the useful part
  of the platform. Model-free runners absorb compute without making remote
  agent narration or a green job icon the verdict.

## Context
- The CLI door verifies authentication, enforces default-deny writes, and
  waits out rate limits to its cap. Only issue comments, issue labels and
  workflow dispatches may be written. Agent-task creation, PR merges,
  approvals, closes, edits and ready operations are refused before `gh` is
  invoked. A rate limit is a wait, never a verdict.
- Inputs reach the build script only through environment variables, never
  shell interpolation. Provenance records requested ref, actual head, tree
  id, timings and fresh reports. Requested/actual mismatch refuses (exit 8);
  stale/missing reports refuse (exit 12); no completed build verdict is
  NOT-EVIDENCE (exit 14).
- Outcome classes (pinned): `GREEN`, `RED`, `RED-AS-EXPECTED`,
  `RED-UNEXPECTED`, `DIED-NO-EVIDENCE`, `NO-EVIDENCE`, with duration from
  artifact provenance. Unexpected reds and the designated timing/allocation/
  thread-leak deaths queue exactly ONE local rerun at the same sha, never a
  second remote retry.
- Mutant dispatch refuses, before anything is sent, a patch that is empty
  against the snapshot, has the green patch's sha256, or whose edited files
  all hash as HEAD. A simulation that did not change the bytes is not a
  simulation.
- Caps and cost: concurrent Actions runs above `cloud.max_runs` refuse
  before dispatch (exit 15); artifact download below `artifacts.min_free_gib`
  refuses (exit 13); the door's rate limit exits 10. A per-session cost
  ledger records minutes, runs, NO-EVIDENCE runs and configured cost. An
  optional session/day spending guard holds NEW dispatches (exit 16),
  without cancelling running work or silently skipping a lane.
- `gh-build.py run` is available in local mode. It never builds locally
  itself; B4.2 owns admitted local execution. `remote:start` and cloud AI
  members remain retired and refuse before effects.
- Guidance: "The Card Is the Contract" (Evidence or nothing; The cloud lane
  lost; GitHub spend has a receipt).

## Doctrine
- Principles engaged: GitHub is compute, not an agent host; evidence is a
  build that happened; exact bytes or refusal; a simulation must take
  effect; new spend stops without hiding running work.
- Why this validation is sufficient: AI-return, false green, unsafe order or
  interpolation, retry storms, fake mutants and silent spend each have a
  killing mutant.

## DESIGN SELF-CHECK
1. Claims and pins: every build/evidence/cost claim maps to (a)-(f); no claim
   treats a job conclusion or remote agent report as the verdict.
2. Constants: outcome classes, exit codes and ledger keys come from the
   build/cost modules; tests import them rather than re-type.
3. Shared state and test order: run fixtures are independent; conclusion
   and upload order, and one-rerun order, are asserted explicitly.
4. Inherited environment: every CLI fixture scrubs inherited git and
   workflow-mode variables, then sets only the mode/input under test.
5. Mutant kills: M1-M6 name their tests; M5's green patch control proves
   the real mutant differs before the refusal cases run.
6. Composition: B2.2 owns mode; B4.2 owns local builds; B5.1 consumes these
   run records and cost ledger without a second classifier.
