## Summary
- What is wanted: the LOCAL desk handoff (`templates/local-handoff.md` and
  `scripts/render-handoff.py`), its rolling-report contract, and
  `scripts/run-size-watch.py`. A handoff names the role and resolved
  `model:effort`, branch, base, card reference, inputs, allowed writes and
  report path. The desk reads the card and doctrine through the local
  session's normal channels. No cloud task is launched and no READ receipt
  is claimed.
- Why it matters: local desks fail by context growth and interruption, not
  by a remote task API. The brief must route explicitly, the report must be
  resumable, and the size watch must force a handoff before the provider
  destroys the context.

## Context
- Brief slots (pinned): `[[step]]`, `[[role]]`, `[[model_effort]]`,
  `[[repo]]`, `[[step_path]]`, `[[card]]`, `[[branch]]`, `[[base_sha]]`,
  `[[inputs]]`, `[[may_add]]`, `[[report]]`, `[[completion_sentinel]]`.
  Missing role or effort is an error, never inheritance from the
  coordinator. A card is referenced, not silently copied into the brief.
- Rolling report (pinned): it starts `DRAFT status: <done>/<total> records,
  phase: <phase>` and is updated after each measured record. A HANDOFF
  request adds `HANDOFF: done <records>; next <first open item>; restore
  <IF-CUT state or none>` at the top and ends `HANDOFF-<card>: <report
  path>`. The completion sentinel is written LAST and only at close.
- Size watch (pinned): one threshold table produces
  `SIZE <run> <bytes> <OK|WATCH|HANDOFF|UNKNOWN>`. WATCH means shorten tool
  output; HANDOFF means update the rolling report and hand off; UNKNOWN
  names the unreadable status/session file and is never OK. Thresholds are
  configuration, not prose duplicated across scripts.
- Forbidden claims: no `READ STEP`/`READ COMMENT`, no remote task id, no
  statement that quoting a source proves a local model read it. Completion
  receipts prove completion, not comprehension.
- Guidance: "The Card Is the Contract" (local desks, rolling reports,
  request-size recovery); PROTOCOL.md (receipts as work evidence).

## Failing test
- Test file / class: `tests/test_local_handoff.py::TestBriefReportAndSize`
- Guarantee it asserts: (a) every slot renders or the render refuses with
  the slot named, and missing role/effort never inherits; (b) the brief
  contains no fixture card-body sentence and no cloud/READ-receipt claim;
  (c) a rolling report accepts the completion sentinel only as its last
  record, while an early sentinel leaves it PARTIAL; (d) HANDOFF carries
  done/next/restore and the report path; (e) the size watch emits the four
  states at fixture boundaries and treats an unreadable file as UNKNOWN,
  never OK.
- Command: `python3 -m pytest tests/test_local_handoff.py -q`
- exact failure on the base commit (before `scripts/render-handoff.py` and
  `scripts/run-size-watch.py` exist): exit 1, `ModuleNotFoundError` /
  `FileNotFoundError` naming the missing script.

## Mutants
- M1 (silent inheritance): missing `model_effort` resolves to the
  coordinator's model. `TestBriefReportAndSize::test_explicit_role_and_effort`
  must turn red.
- M2 (premature completion): the sentinel is accepted before all records
  are complete. `test_sentinel_only_at_close` must turn red.
- M3 (unknown is healthy): an unreadable session file emits OK, or a
  HANDOFF-sized run emits no handoff instruction.
  `test_size_watch_fails_toward_handoff` must turn red.
- M4 (archived guarantee): the brief gains `READ STEP` or says quoted lines
  prove local reading. `test_no_read_receipt_claim` must turn red.

  never becomes healthy.

## DESIGN SELF-CHECK
1. Claims and pins: brief, report, HANDOFF and size-watch claims map to
   guarantee (a)-(e); no proof-of-reading property is claimed.
2. Constants: slot names, sentinel placement and size thresholds have one
   canonical source; tests do not re-type a second threshold table.
3. Shared state and test order: report fixtures are independent; sentinel
   position is the only required order and is exercised explicitly.
4. Inherited environment: renderer and size-watch fixtures run with clean
   environments and no inherited git repository variables.
5. Mutant kills: M1-M4 name their killing tests; M3 also has an OK boundary
   control proving the watch does not always degrade.

   states; their file sets do not overlap except through the named contract.
