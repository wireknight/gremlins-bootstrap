## Summary
- What is wanted: the citation canon everything else joins on, and its
  linter (`lint-anchors.py`). A canonical citation uses the form
  `@Anchor(file="...", anchor="...", quote="...")` (plus `HR-N` for laws):
  it names its target by file and stable identifier (heading slug, declared
  symbol, or key path — never a fragile line number) and carries the
  verbatim `quote` that must appear in that anchor's region. The linter
  checks every `@Anchor` in `--check` mode (including `--index` to scan the
  staged git index at pre-commit), canonicalizes resolvable legacy cites in
  `--normalize` mode, refreshes drifted quotes in `--fix` mode while NEVER
  inventing or substituting a missing file or anchor, and edits nothing in
  `--check` mode.
- Why it matters: this is the join key of the whole loop. The digest indexes
  laws by number; the write gate's refusal points at the canonical section;
  local handoffs and completion receipts address work by card and run;
  evidence files use the same identifiers; docs cite code by symbol. Strip the anchors and every piece
  still runs; nothing still agrees.

## Context
- A page number or line number is an address; an anchor is a name. Addresses
  shift when files are edited; names do not, and the `quote` is the
  semantic-drift tripwire when code changes underneath a surviving symbol.
- Canonical form (pinned):
  `@Anchor(file="relative/or/bare/path.py", anchor="Class.method", quote="def place_order():")`
  for code targets (`quote` is mandatory for code targets);
  `@Anchor(file="docs/...", anchor="heading-slug", quote="Heading Text")`
  for markdown targets. Fenced code blocks and markdown link targets are
  blanked so examples are not mangled.
- Verdict classes (pinned): `ok`, `missing_file`, `missing_anchor`,
  `quote_drift`, `quote_required`, `legacy_format`, `parse_error`.
- The fixer never invents an anchor: `--fix` refreshes `quote_drift` and
  `quote_required` when the anchor still resolves, but `missing_file` and
  `missing_anchor` stay findings and exit 1. `--index` reads from the git
  index (`git show :path`) and refuses `--fix` or `--normalize` (exit 2).
- Guidance: "The Anti-Rot Machine" (the anchoring system; the fixer never
  invents an anchor; run-scoped evidence); "Dura Lex, Sed Lex"
  (cite-by-reference as the hook-enforced rule).

## Failing test
- Test file / class: `tests/test_anchors.py::TestCanon`
- Guarantee it asserts: (a) a fixture `@Anchor(file=..., anchor=..., quote=...)`
  whose file and symbol/heading resolve and whose quote matches passes clean
  (`ok`); (b) a resolving anchor with a drifted quote fails with
  `quote_drift`, naming the anchor and region; (c) an unresolvable anchor
  (`missing_anchor` or `missing_file`) fails and `--fix` still exits 1
  without inventing or substituting an anchor; (d) `--check` on a failing
  fixture leaves every input byte unchanged (pinned by sha256); (e)
  `--index` reads the staged blob from the git index and rejects `--fix` /
  `--normalize` with exit 2.
- Command: `python3 -m pytest tests/test_anchors.py -q`
- exact failure on the base commit (when the red test is run before
  `scripts/lint-anchors.py` exists): exit code 1, `FileNotFoundError` /
  `AssertionError` (`scripts/lint-anchors.py` not found).

## Mutants
- M1 (quote laundering in `--check`): a drifted quote is accepted as `ok`.
  `TestCanon::test_drifted_quote_fails` must turn red.
- M2 (anchor invention in `--fix`): a `missing_anchor` is rewritten to the
  nearest declared symbol and exits 0.
  `test_unresolvable_never_invented` must turn red.
- M3 (silent pass): a failing fixture in `--check` exits 0.
  `test_failures_are_loud` must turn red.
- M4 (self-edit in `--check` or `--index` rewrite): `--check` modifies the
  file or `--index --fix` is allowed. `test_check_edits_nothing_and_index_guard`
  must turn red.

## Doctrine
- Principles engaged: an anchor is a name, not an address; the fixer never
  invents an anchor; quote-verified cites only; findings are reported, never
  laundered.
- Why this validation is sufficient: every way a canon can rot silently
  (laundered quotes, invented anchors, quiet passes, `--check` self-edits)
  is a mutant.

## DESIGN SELF-CHECK
1. Claims and pins: canon, verdict, fixer and index claims map to (a)-(e);
   no claim says a missing target can be repaired by invention.
2. Constants: `@Anchor` keys and verdict classes come from the anchor engine;
   tests import them instead of maintaining a second grammar.
3. Shared state and test order: fixture repositories are independent;
   staged-index fixtures construct their index explicitly per case.
4. Inherited environment: linter fixtures remove inherited git repository
   variables before using the real index.
5. Mutant kills: M1-M4 name their tests; the valid-anchor control proves
   the linter does not simply reject every citation.
6. Composition: no predecessor. B1.1, B1.3, B3.3 and B5.2 consume this one
   engine; they must not create parallel anchor implementations.
