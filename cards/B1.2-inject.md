## Summary
- What is wanted: a hook that, at session start, reads the canonical doctrine
  file and the digest surface from B1.1, and emits the session slice (the
  numbering table of contents; bodies by pointer) into the session's
  additional context — plus the compaction re-arm that re-injects the
  bounded index on the first code-touching call after a context compaction
  or in a child context that never ran SessionStart.
- Why it matters: the law must be present where work happens, and its absence
  must be visible. Injection is the first enforcement; its failure is a
  system property failing, so it fails loud.

## Context
- The canonical file is one markdown file per layer; the slice is generated
  from it at session start, never stored by hand, so it cannot fork.
- The project layer resolves from the SESSION cwd, not from a child desk's
  later cwd or worktree. A `cd` by a specialist must not silently rebind the
  project's doctrine to another root.
- Smallness is by reference, guarded by B1.1's loud per-layer budget (never
  silent truncation).
- The envelope is the runtime's session-start additional-context structure.
- Fail-loud contract: an unreadable or missing canonical file, or an
  over-budget digest (exit 3 from B1.1), is not an empty slice; it is a loud
  failure naming the path or budget.
- Guidance: "Dura Lex, Sed Lex" (the injector and the enforcement; the ban on
  copying the law is itself a law); "Untrusted Labor in a Trusted Envelope"
  (the compaction re-arm); "The Card Is the Contract" (the pointer resolves
  to the current text whenever it is followed).

## Failing test
- Test file / class: `tests/test_session_inject.py::TestInjectEnvelope`
- Guarantee it asserts: (a) with a readable fixture, stdout is a valid
  envelope whose payload contains the numbering index for both layers;
  (b) with the canonical file missing, the run prints a one-line error naming
  the path and exits non-zero; (c) the payload carries the literal
  canonical-pointer line (bodies by pointer), and no rule body text; (d) a
  post-compaction or un-initialized child context re-arms the bounded
  re-injection index before its first code-touching call; (e) a child that
  changes cwd still resolves the project layer from the session cwd.
- Command: `python3 -m pytest tests/test_session_inject.py -q`
- exact failure on the base commit (when the red test is run before
  `scripts/doctrine-session-inject.sh` exists): exit code 1,
  `FileNotFoundError` / `AssertionError`
  (`scripts/doctrine-session-inject.sh` not found).

## Mutants
- M1 (silent degrade): missing canonical file yields an empty envelope and
  exit 0. `TestInjectEnvelope::test_missing_source_fails_loud` must turn red.
- M2 (body smuggler): the payload embeds the first rule's body text instead
  of the pointer. `test_payload_is_index_not_bodies` must turn red.
- M3 (stale slice): the slice is read from a cached file when the canonical
  file changed. `test_slice_generated_per_run` must turn red.
- M4 (re-arm skipped): a post-compaction call proceeds without re-arming the
  index. `test_compaction_rearm_fires` must turn red.
- M5 (project-root rebinding): a child cwd silently selects a different
  project doctrine layer. `test_project_layer_uses_session_cwd` must turn red.

## Doctrine
- Principles engaged: injection fails loud (its failure is a system-property
  failure); smallness by reference; the generated slice cannot fork;
  compaction never strips the law.
- Why this validation is sufficient: the only tolerable behaviors (valid
  envelope, loud failure, re-arm) are pinned; every quiet failure mode is a
  mutant.

## DESIGN SELF-CHECK
1. Claims and pins: envelope, freshness, failure, re-arm and session-cwd
   claims map to (a)-(e); no claim permits silent degradation.
2. Constants: the canonical pointer line and envelope shape come from B1.1
   and the runtime contract; tests read them rather than invent a second.
3. Shared state and test order: each session fixture has independent state;
   compaction precedes the code-touching call only in the re-arm case.
4. Inherited environment: every child fixture sets session cwd explicitly
   and varies only child cwd, preventing accidental project-root leakage.
5. Mutant kills: M1-M5 name their tests; valid injection and unchanged-root
   controls prove the envelope still works.
6. Composition: B1.1 supplies the digest; B2.2 wires local session start;
   no other card owns project-layer path resolution.
